# Career portfolio

Reconstructed product and operational work samples.

- `ats-inline-help/`: ATS contextual help
- `crm-account-management/`: customer account and contact management
- `multi-tenant-platform/`: shared platform and customer configuration
- `multilingual-website/`: English, French and Arabic recruitment website with four presentation options

Pages request no indexing and use separate browser-side review-link checks. These are deterrents, not authentication. This public repository exposes the source and link checks. GitHub Pages cannot enforce a bot block. The robots.txt in this project directory is advisory only: crawlers normally read robots.txt at the hosting origin root, which this project does not control.

Examples use fictional data and were reconstructed with AI assistance. No production integrations or authentication are implemented.
