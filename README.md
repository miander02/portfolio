# ATS Inline Help System

An interactive product work sample reconstructing contextual help delivered within a recruitment platform.

## Context and my role

I identified repeated customer documentation as a source of wasted time and delays. I designed and specified the help management workflow and ATS user experience, tested the feature and oversaw delivery and later improvements. Engineering implemented the original software, and a team member reporting to me supported content preparation and rollout.

This demo was prepared with AI assistance from my description and surviving project documents. It is a reconstruction, not the original application or source code.

## Review the demo

Open `index.html` in a browser, or use the GitHub Pages link once enabled.

1. Browse Help pages and open Candidate search.
2. Review the single category hierarchy, read-only page code, status, role guidance and system selection.
3. Use Preview in place to review content in management.
4. Open ATS preview and compare User with Admin, and System A with System B.
5. Set the entry to Inactive and confirm the ATS help control is hidden.
6. Read Behaviour & checks for requirements and delivery context.

## Product decisions

The first release focused on generic contextual guidance to reduce duplicated documentation. Page association evolved from URLs to Engineering-supplied page codes and a header listener. Categorisation, permissions, preview and embedded YouTube videos were later developments. The third phase, a fully interactive and searchable help platform, was put on hold to prioritise other development. A separate knowledge base was developed later for a broader range of projects.

## Scope of this reconstruction

- Fictional candidate data and customer systems.
- Role-specific field layout, codes, category paths and example content are illustrative.
- Browser-local interactions only; edits reset on refresh.
- The editor toolbar is visual only.
- No production database, listener, authentication or server-side permissions.
- Candidate search is the worked example; other directory entries demonstrate navigation.

This repository is separate from my other projects.
