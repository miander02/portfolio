Multilingual Website & Localisation Framework

The opportunity

Support multiple languages and regional presentation requirements within one website, avoiding separate builds and ongoing maintenance for each language.

My ownership

I defined the approach and led development of a reusable multilingual framework at Zero-One Design. Fixed interface text, including form labels and standard messages, was converted into language configuration variables. Menus, links, page content, sectors, locations and content plugins supported editable language variants within the database.

Translation and testing

Customers supplied translations, and we sourced external translators for some projects. Translations for fixed interface text were transferred from Excel into the language configuration. I oversaw the whole process, including implementation, client review, testing and delivery.

The outcome

The same underlying website could support different languages without rebuilding it for each one. The framework was used across projects involving Welsh, French, Spanish, German, Norwegian and Arabic. Arabic also required interface changes for right-to-left presentation.

About this demonstration

This modern reconstruction demonstrates English, French and Arabic across a homepage, job search, job details and an application form. The brand, vacancies, quotations and all content are illustrative. Sample translations were prepared with AI assistance for this draft and are not original customer translations. No application is submitted, stored or transmitted. Arabic is included as a right-to-left demonstration. Sample Arabic translations require fluent-speaker review.
